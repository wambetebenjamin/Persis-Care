# Persis Care

Care close. Guidance clear.

Offline-friendly protocols, checklists and referral companions for community health workers supporting maternal, child and primary care.

## Health and safety disclaimer
Persis Care is an educational support tool only. It does not replace clinical judgment, national guidelines or trained medical care. Follow current Ministry of Health protocols and local referral pathways. It is not a medical device and does not diagnose, prescribe or provide emergency services. No patient records are stored. Never enter or transmit personally identifiable patient information.

Before deployment, every health checklist must be reviewed and approved by qualified local clinical and public-health reviewers against current country-specific guidance. Content here is intentionally framed as prompts for supervision, not treatment instructions.

## Development
Requires Node.js compatible with Next.js 16.

```sh
npm install
npm run dev
npm run build
```
